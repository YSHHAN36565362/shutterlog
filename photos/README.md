# photos/ — 여기에 사진을 넣습니다

## 폴더 이름 규칙

```
YYYY-MM_영문슬러그
```

예: `2024-08_kansai` · `2025-08_europe` · `2026-02_tokyo`

| 규칙 | 이유 |
|---|---|
| 연-월로 시작 | 이름순 정렬이 곧 시간순이 됩니다 |
| 구분자는 `_` 하나 | 날짜와 이름을 나누는 기준입니다 |
| 슬러그는 영문 소문자 + `-` | URL 에 그대로 들어갑니다 |
| 한글·일본어·공백 금지 | GitHub Pages 에서 경로가 깨질 수 있습니다 |

폴더 이름을 바꾸면 `../data/trips.meta.json` 의 `folder` 값도 **같이** 바꿔야 합니다.

## 넣는 사진

- **베스트 컷만.** 여행당 10~20장이면 충분합니다.
- JPEG 권장. PNG·WebP 도 읽습니다. RAW 는 EXIF 만 읽고 이미지는 만들지 못합니다.
- 파일명은 카메라가 준 그대로(`DSC01234.JPG`)면 됩니다.
- 원본 해상도 그대로 넣어도 됩니다 — `build.py` 가 `../thumbs/` 에 줄여서 따로 만듭니다.
  **원본은 수정하지 않습니다.**

## 넣은 뒤

```sh
cd ..
python3 build.py
```

그러면 EXIF 를 읽어 갤러리에 촬영 일시순으로 놓고, 초점거리·조리개·ISO 정렬도
바로 동작합니다. 대표 사진을 직접 고르려면 `data/trips.meta.json` 의 해당 여행에
`"cover": "DSC01234.JPG"` 를 넣으세요.

## 새 여행을 추가하려면

1. 여기에 `YYYY-MM_슬러그` 폴더를 만들고 사진을 넣습니다
2. `../data/trips.meta.json` 의 `trips` 배열에 항목을 하나 복사해 붙이고
   `folder` · `date` · `title`(日/한/EN) · `region` · `countries` · `spots` 를 고칩니다
3. `python3 build.py`
